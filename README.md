# FiveShu Saam Guide

Mobile-first visual reference for the Five-Shu mother-child method and Korean Saam acupuncture formulas.

## What it includes

- Searchable Twelve Meridian reference
- Mother point / child point lookup
- Saam Jeong-gyeok and Seung-gyeok four-point formulas
- Interactive deficiency/excess formula calculator
- Chinese-first explanatory guide and clinical safety boundaries
- Responsive layout, dark mode, keyboard support, and reduced-motion support

## Run locally

This is a dependency-free static web app. Open `index.html` directly, or serve the folder:

```bash
python -m http.server 4173
```

Then open `http://localhost:4173`.

## Medical scope

This project is for professional education and reference. It does not provide self-needling depth, angle, manipulation, or retention instructions and does not replace diagnosis, emergency assessment, or necessary conventional treatment.

## Design direction

The interface uses AcuAcu as a design reference only: warm neutral canvas, bold color coding, dark keylines, offset shadows, compact information cards, and mobile-first navigation. No AcuAcu code, branding, or proprietary assets are included.
